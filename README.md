Intrusion Detection and Prevention System (IDPS) developed to monitor Wi-Fi networks, detect malicious activities, identify cyber attacks, and automatically block suspicious intrusions in real time using Deep Learning techniques. The system uses a CNN (Convolutional Neural Network) model trained on the NSL-KDD dataset for intelligent intrusion detection, attack classification, and network traffic analysis. This project includes a web application, Android mobile application, backend server, real-time packet monitoring, and automated attack prevention mechanisms to improve network security and protect users from unauthorized access. The system is capable of detecting attacks such as DoS, Probe, R2L, and U2R attacks by continuously analyzing network packets and suspicious traffic patterns. It also includes an AI-powered chatbot integrated using Google API Key services to assist users by answering cybersecurity-related queries and providing intelligent support. In addition, the platform contains a secure expert chat system that enables users to communicate directly with cybersecurity experts for guidance, reporting issues, and receiving technical assistance. The project is developed using Python, Django, TensorFlow, Scapy, HTML, CSS, JavaScript, Android Studio, Java/XML, and MySQL. Major functionalities include user authentication, real-time intrusion detection, automatic attack blocking, packet capturing, traffic analysis, AI chatbot integration, expert-user communication system, alert notifications, attack monitoring dashboard, and Android-based monitoring support. The system is designed for educational, research, and cybersecurity monitoring purposes, with future enhancements including cloud deployment, advanced threat intelligence integration, live traffic visualization, and enhanced real-time security analytics.
